Bugs fixed
- Session and blocked-app prefs used apply(); reboot could drop state. Now commit().
- App picker used getInstalledApplications; API 34 package visibility hid launchable apps.
  Now queryIntentActivities(ACTION_MAIN + CATEGORY_LAUNCHER).
- Debug-only adb session hook (not in release) so NFC is not required for emulator proof.
